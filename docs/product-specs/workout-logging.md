# Workout Logging

## 사용자 문제
헬스장에서 세트 사이 짧은 휴식 동안 빠르게 기록하고 싶다.

## 핵심 시나리오
1. 운동 시작 → 종목 선택 → 세트(무게·횟수) 입력 → 완료
2. 이전 기록을 보며 같은 종목 반복 입력 (지난번 값 프리필)
3. 운동 종료 → 요약 (총 볼륨, 시간)

## 수용 기준
- [x] 세트 1개 추가가 탭 2번 이내 (스테퍼 조정 → 세트 추가)
- [ ] 네트워크 끊김 중에도 기록 가능 (재연결 시 동기화) — [RELIABILITY](../RELIABILITY.md) (TD-002, 현재는 낙관적 업데이트 + 실패 시 롤백만)
- [ ] kg/lb 단위 설정 반영 (TD-003)
